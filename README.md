# КВАНТ-СТРОЙ

Лендинг строительной компании «КВАНТ-СТРОЙ» на Next.js 14 (App Router), TypeScript, Tailwind CSS и Framer Motion.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
```

Прод-сборка:

```bash
npm run build
npm run start
```

## Структура

```
app/
  layout.tsx           # Montserrat, метаданные с шаблоном, общие Header и Footer
  page.tsx             # Главная
  services/page.tsx    # Услуги и материалы
  portfolio/page.tsx   # Наши работы + отзывы
  prices/page.tsx      # Цены и документы
  globals.css          # Tailwind + утилиты .btn-accent / .glass-card
components/
  Header.tsx             # sticky-шапка, backdrop-blur при скролле, бургер, активный пункт
  Hero.tsx               # заголовок, CTA, mesh-градиент и плавающие фигуры
  Services.tsx           # карточки 01/02/03 + блок «До / После» (главная)
  BeforeAfterSlider.tsx  # интерактивное сравнение (pointer events + clip-path)
  Calculator.tsx         # калькулятор стоимости (glassmorphism)
  Stats.tsx              # 4 показателя с анимацией счётчика при скролле
  Documents.tsx          # карточки скачивания PDF (variant="cta" для главной)
  PageHero.tsx           # общая шапка внутренних страниц
  ServicesDetail.tsx     # развёрнутые услуги + аккордеон с техданными
  PortfolioGallery.tsx   # сетка объектов 3×2 с hover-зумом
  Reviews.tsx            # карусель отзывов на embla-carousel-react
  PriceList.tsx          # светлая секция (#F5F5F5) со стартовыми ценами
  Footer.tsx             # CTA, навигация, контакты, копирайт
lib/
  motion.ts         # общие варианты анимаций Framer Motion
  site.ts           # контакты, меню и список документов в одном месте
```

## Маршруты

| Путь         | Содержимое                                                    |
| ------------ | ------------------------------------------------------------- |
| `/`          | Hero, услуги, «До/После», калькулятор, цифры, документы        |
| `/services`  | Три направления с техданными в аккордеоне, документы           |
| `/portfolio` | Галерея объектов 3×2, карусель отзывов                         |
| `/prices`    | Стартовые цены, документы для скачивания                       |

## Логика калькулятора

Стоимость считается как `площадь × ставка` (от минимальной до максимальной, только работы) и
пересчитывается мгновенно (`useState` + `useEffect`), цифры плавно анимируются. Ставки за м² заданы
в `components/Calculator.tsx`, полный прайс — в `lib/prices.ts`:

| Тип работ                              | Ставка за м²       |
| -------------------------------------- | ------------------ |
| Укладка ламината                       | 700 – 1 200 ₽      |
| Укладка кварцвинила                    | 1 200 – 2 500 ₽    |
| Укладка керамогранита                  | 3 500 – 12 000 ₽   |
| Укладка линолеума                      | 400 – 1 500 ₽      |
| Монтаж обоев                           | 600 – 1 300 ₽      |
| Монтаж моющих / антивандальных (1 слой) | 250 ₽             |
| Демонтаж обоев (1 слой)                | 150 ₽              |
| Устройство стяжки пола                 | от 700 ₽           |

По умолчанию: 75 м² × ламинат = **52 500 – 90 000 ₽**.

## Что стоит заменить на реальные данные

- Плейсхолдеры «ДО»/«ПОСЛЕ» в `BeforeAfterSlider` — передайте пропсы `beforeSrc` / `afterSrc`
  с путями к фотографиям объектов.
- Заглушки галереи в `PortfolioGallery.tsx` — замените градиентный блок на `next/image`.
- Ссылки на PDF в `lib/site.ts` (`documents[].file`) сейчас ведут на `#`; положите файлы
  в `public/docs/` и укажите пути — атрибут `download` уже проставлен.
- Кнопки «Оставить заявку» и «Получить расчёт» пока не отправляют форму — подключите модалку
  или обработчик отправки в CRM.
